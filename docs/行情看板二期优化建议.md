## 1. 需求概要

| 编号 | 用户诉求 | 当前问题 | 优先级 |
|---|---|---|---|
| W1 | **看板内筛选搜索**：已加入自选的标的，可以按代码/名称快速过滤定位 | DataTable 无筛选输入框，用户需在几十个标的中手动查找 | **P0** |
| W2 | **添加搜索栏支持全量搜索**：上方搜索框应能搜到未缓存的标的（全市场 A/港股），而非仅限已缓存 | `_get_cached_symbols()` 只返回 `cache_catalog` 中有数据的标的。用户想关注的标的如果还没缓存过数据，无法添加到看板。用户必须先到数据中心获取数据再回来看板添加，路径割裂 | **P0** |
| W3 | **日线图去除节假**：日 K 线图上周末和节假日留白，看起来很松散，有效信息被稀释 | `bars_daily` 表无周末数据，但 plotly 默认用连续时间轴，在周末处产生断档/留白 | **P1** |

## 2. 现状分析

### 2.1 W1 看板内筛选搜索

**代码事实**：
- `_build_quote_table` 生成的 DataTable 无筛选功能。
- DataTable 有 `filter_action="native"` 属性可用（Dash 内置的客户端筛选），但当前未启用。

**方案**：在 DataTable 上方新增一个 `dbc.Input`（`qb-table-filter`），监听其输入值，实时过滤表格行（客户端侧，无须服务端查询）。

**交互**：
- 输入框 placeholder = "筛选代码/名称..."
- 用户输入即过滤（无 debounce，本地数据不须发请求）
- 清空输入框恢复全量显示

### 2.2 W2 添加搜索全量

**代码事实**：
- `load_qb_symbols`（第 331 行）调用 `_get_cached_symbols()` → 只返回 cache_catalog 中有覆盖的标的
- `search_symbols` 服务（`data_center_service.py`）已支持按名称/代码/拼音模糊搜索全量 A/港股，只需在看板侧复用该服务

**方案**：
- 将 Dropdown 改为支持输入搜索的 `dcc.Dropdown` 已支持 `searchable=True`（默认），但需要动态加载 options。
- 新增搜索回调：监听 `qb-add-symbol-dropdown.search_value` → 调用 `get_data_service().search_symbols(query)` → 返回匹配结果。
- 添加时判断：若标的是死标（`_is_dead_symbol`），自动触发一次基础数据获取（`fetch_bars`），并在 UI 提示"正在加载数据"。
- 简化方案：对于非缓存标的，添加时允许加入 watchlist（取消 `_is_dead_symbol` 拦截），但在表格中显示"无数据"状态，并自动触发后台数据获取。

### 2.3 W3 日线去除节假日

**代码事实**：
- `_fetch_daily_bars` 从 `bars_daily` 表读取数据，返回的日期是连续的（已经跳过非交易日）。
- 但 plotly 的时间轴（type="date"）会在连续日期之间为缺失的周末/节假日留空，即使数据中没有这些日期。
- 当前 `_build_daily_chart` 未设置 `rangebreaks`。

**方案**：
- 在 `_build_daily_chart` 的 `fig.update_xaxes` 中设置 `rangebreaks=[dict(bounds=["sat", "mon"])]`，自动跳过周末。
- 对于法定节假日，因其无固定规律，不做自动识别。建议未来在数据层增加节假日表，然后用 `rangebreaks` 的 `values` 参数指定。

## 3. 功能需求（FR）

### FR-W1 看板列表筛选

- DataTable 上方新增 `dbc.Input(id="qb-table-filter", placeholder="筛选代码/名称...")`。
- 新增回调：监听 `qb-table-filter.value` → 过滤 DataTable 的 `data` 属性。
- 过滤逻辑：遍历 data 中每条记录的 `code` 和 `name` 字段，若任一包含输入字符串（不区分大小写）则保留。
- 输入为空时显示全部。

**验收**：
- [ ] 输入"茅台" → 表格只显示贵州茅台
- [ ] 输入"600" → 表格只显示代码包含600的标的
- [ ] 清空输入 → 恢复全部
- [ ] 筛选不影响底部已选计数和删除操作

### FR-W2 添加搜索支持全量标的

- `qb-add-symbol-dropdown` 改为动态搜索：Input `qb-add-symbol-dropdown.search_value`。
- 搜索回调调用 `get_data_service().search_symbols(query)`（与数据中心相同的全市场搜索接口）。
- 结果限制：返回前 20 个匹配项。
- 添加时放开 `_is_dead_symbol` 限制：未缓存标的可以加入 watchlist，但显示"数据待获取"状态。
- 新增「批量添加」能力：在下拉列表中支持多选（`multi=True`）。

**验收**：
- [ ] 搜索框输入"茅台" → 下拉出现贵州茅台（即使未缓存）
- [ ] 搜索框输入"600519" → 精确命中
- [ ] 未缓存标的加入看板后，表格中显示"等待获取"而非空白或报错
- [ ] 已缓存标的加入看板行为不变
- [ ] 搜索无结果时显示"未找到匹配标的"

### FR-W3 日线图跳过周末

- `_build_daily_chart` 的 `fig.update_xaxes` 增加 `rangebreaks=[dict(bounds=["sat", "mon"])]`。
- 图表的 X 轴保持连续的交易日序列，周末不显示留白。

**验收**：
- [ ] 日线图 X 轴上无周末间隔，K 线连续排列
- [ ] hover 时日期显示正确（不丢失交易日）
- [ ] rangeslider 中的小图也无周末间隔

## 4. 产品决策

1. **W1 筛选为客户端本地过滤**：不涉及服务端查询，数据已在 DataTable 的 `data` 属性中。输入即过滤，零网络开销。
2. **W2 全量搜索复用现有 search_symbols 服务**：`DataCenterService.search_symbols` 已支持中文名称/代码/拼音模糊搜索，此次不做新增服务方法。
3. **W2 未缓存标的不阻止添加**：之前的设计"防死标"过于严格，导致用户无法在看板维度管理未缓存标的。改为允许添加 + 标记"数据待获取"状态。
4. **W3 节假日只覆盖周末**：法定节假日无固定规律可循，自动识别需引入节假日数据表（结构性变更）。本次不做，留待后续。

## 7. 评审记录（开发 / 设计 / 测试）

> 评审日期 2026-07-28。基于代码走查（`quote_callbacks.py` `load_qb_symbols` / `update_watchlist` / `_build_daily_chart` / `_build_quote_table`）。

### 开发视角

| 编号 | 发现 | 严重度 | 修订动作 |
|---|---|---|---|
| D1 | **W1 筛选方案需调整**：PRD 写"过滤 DataTable 的 `data` 属性"但 Dash DataTable 的 `data` 属性更新需通过回调 Output 实现。W1 应新增独立回调输出 `qb-data-table.data`，Input `qb-table-filter.value` + State 全量数据。 | 中 | 新增回调监听 `qb-table-filter.value`，Output `qb-data-table.data`，State 全量数据从 `_fetch_quote_data` 结果缓存。 |
| D2 | **`multi=True` 后 value 类型变化**：`dcc.Dropdown(multi=True)` 的 `value` 为 `list[str]` 而非 `str`。`update_watchlist` 中 `new_symbol` 处理逻辑需改为遍历列表，对每个 symbol 执行去重添加。 | 高 | `update_watchlist` 新增 `isinstance(new_symbol, list)` 分支。 |
| D3 | **`search_value` 与 `value` 分离**：`dcc.Dropdown` 的 `search_value` 是用户输入的搜索文本，`value` 是已选值。搜索回调需以 `search_value` 为 Input，Output 仅 `options`（不修改 `value`）。 | 中 | 新增独立回调处理搜索，不干扰 `load_qb_symbols`。 |
| D4 | **初始加载仍需已缓存标的**：搜索回调仅处理用户输入时的动态搜索。初始页面加载时仍用 `load_qb_symbols` 加载已缓存标的作为下拉备选。两者不冲突。 | 低 | `load_qb_symbols` 保持不变（路由触发时加载缓存）；搜索回调独立注册（用户输入时触发）。 |
| D5 | **`rangebreaks` 在 subplot 中须指定 row**：`make_subplots` 模式下 `rangebreaks` 不能直接用 `fig.update_xaxes(rangebreaks=[...])`，须指定 `row=1`，否则影响所有 row 的 xaxis。 | 中 | `fig.update_xaxes(rangebreaks=[dict(bounds=["sat","mon"])], row=1)` |

### 设计视角

| 编号 | 发现 | 严重度 | 建议 |
|---|---|---|---|
| DES-1 | **筛选与删除区域布局**：筛选框与批量删除 bar 都在表格上方。建议筛选框独立一行，批量删除 bar 紧贴表格上方。 | 低 | 筛选框占独立 Row，功能分离。 |
