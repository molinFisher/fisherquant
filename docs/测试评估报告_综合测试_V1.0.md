## 4. 本轮补齐动作（高价值、可单测）

新增/修订 3 个测试文件，33 个用例，精准命中上述缺口：

### 4.1 `tests/unit/test_backtest_readiness_adj.py`（新增，8 例）
锁定**策略中心缓存联动（P0）**此前从未被断言的回测入口关键路径：
- **就绪阻断分支**：`readiness.blocking=True` 时 `run_backtest` 提前返回「数据未就绪」清单且**不构造回测引擎**（AC-1 / D1 不静默空跑）。
- **adj_caliber 留痕**：成功路径下 `serializer.save` 的 metadata 含 `adj_caliber`（A股→`qfq`、非A股→`none`），保证 P0-2 收益口径正确可追溯。
- **部分缺失仍跑**：非全缺时仍执行回测并在结果区显式提示「被跳过」标的。
- `_adj_type_for` / `_render_readiness_manifest` 纯函数单测。

### 4.2 `tests/unit/test_backtest_serializer.py`（新增，10 例）

## 6. 观察与建议（非阻塞）

1. **可转债涨跌停规则疑似口径过粗**：`CBRules.price_limits` 将 `110/113/118/123/127/128` 前缀定为 ±20%、其余 ±30%。但所有可转债代码均以 11/12/13 开头，意味着大量可转债落在 ±30% 档，与实际「可转债普遍 ±20%（上市首日/特定情形 ±30%）」的惯例可能存在偏差。建议产品/量化确认该分类是否为预期行为（当前测试已锁定既有实现，如需调整须同步改规则与测试）。
2. **`app.py` 0% 为测量假象**：建议后续用 `--cov-context` 或在集成冒烟中显式断言回调注册数，消除误报。
3. **遗留 `_broken_test_*`**：`tests/integration/_broken_test_data_download.py` 与 `tests/unit/_broken_test_auto_fixer.py` 引用已删除的 `fisher_temp` 模块，且因文件名不匹配 `test_*.py` 而不被收集。属死代码/技术债，建议清理或修复模块引用。
4. **`store/repository.py`(64%)、`realtime_daemon.py`(67%)、`strategy_wizard_callbacks.py`(68%)** 仍有提升空间，但多涉 DB/线程/网络，单测性价比低于本轮已补项，建议下阶段按需补充。
