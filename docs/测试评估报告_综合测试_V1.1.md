## 4. 本轮补齐动作（高价值、可单测）

新增 3 个测试文件，共 **20 个用例**，并修复 1 处缺陷：

### 4.1 `tests/unit/test_market_suspension.py`（新增，10 例）
直测 `SuspensionService`（此前仅被回测以 mock 间接覆盖）：
- 单日 `add_suspension` / `is_suspended` 命中与未命中、跨标的隔离；
- `add_suspension_range` 含端点、单日区间、重叠区间合并；
- `clear` 清空；
- `load_from_akshare` 三态：① akshare 不可用 → 返回 0 且不抛（离线安全）；② `stock_suspend()` 抛异常 → 返回 0；③ 成功写入（含 `代码`/`symbol` 两种列名、空代码行跳过）；④ 解析异常被吞、不向外抛。
- **覆盖率 48% → 100%。**

### 4.2 `tests/unit/test_risk_audit.py`（新增，5 例）
直测 `AuditLogger`（此前仅经引擎间接触发）：
- `log` 返回结构化记录（event/ts/自定义字段）；
- `records` 累积、`query(event_type)` 过滤、`query(None)` 返回全部；
- 指定 `filepath` 时 JSONL 追加写盘并可重读；
- `clear` 清空内存但**保留已落盘留痕**（穿透式审计语义）。
- **覆盖率 71% → 93%**（仅剩「写盘 OSError 降级警告」分支未直测，属刻意保留的容错路径）。

### 4.3 `tests/unit/test_factor_storage.py`（新增，5 例）
直测 `FactorStorage`：
- `sanitize_column` 清洗（特殊字符→`_`、小写）；
- `save` 新建 → `load` 往返；
- 同标的二次 `save` 按列**合并**（已存在列被更新而非重复追加）；
- `delete` 删除目录；
- `load_with_factors` 与 OHLCV 对齐拼接、因子缺失时回退原表。
- **覆盖率 33% → 100%。**

### 4.4 缺陷修复：`fisher/factor/storage.py`
原 `save` 在「已存文件仅含被重写的列」时，`drop` 后留下 0 列且 height=0 的 DataFrame，导致 `hstack` 抛 `ShapeError`。改为：保留列非空则 `select(keep).hstack(renamed)`，否则直接用 `renamed`。修复后经 `test_save_updates_existing_column` 验证，未影响其余用例。

## 6. 观察与建议（非阻塞）

1. **核心逻辑层下一阶段候选**（本次未补，但可被单测、性价比高）：
   - `store/repository.py`(64%) — 仓储 CRUD；
   - `store/engine.py`(84%)、`analytics/performance.py`(81%)、`scheduler/engine.py`(72%)、`market/rate_limiter.py`(75%)、`config/loader.py`(84%) — 均为纯逻辑/配置，单测成本低。
2. **UI / 网络 / 线程类（by-design 低覆盖，建议保持现状）**：`dash_app/app.py`(0%, 装配入口测量假象)、`dashboard/pages/*`(29%/59%/71%)、`dash_app/callbacks/*`(62%~84%)、`realtime_daemon.py`(67%, 线程)、`market/akshare.py`(69%, 网络)。回调层已由 `dash_harness` 部分隔离单测，剩余靠集成冒烟间接覆盖即可。
3. **`audit.py` 93% 剩余分支**：写盘 OSError 降级警告难以在单测中稳定触发（需强制权限错误），保留为容错路径，不强制覆盖。
4. **遗留 `_broken_test_*` 死代码**：`tests/integration/_broken_test_data_download.py` 与 `tests/unit/_broken_test_auto_fixer.py` 引用已删除模块，因文件名不匹配 `test_*.py` 不被收集，建议清理。
5. **可转债涨跌停口径**（沿用 V1.0 观察）：`CBRules.price_limits` 分类是否贴合「可转债普遍 ±20%」惯例仍需产品/量化确认；当前测试已锁定既有实现，调整须同步改规则与测试。
