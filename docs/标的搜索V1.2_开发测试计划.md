## 1. 现状核查结论（作为改造起点）

| 位置 | 现状 | 本期动作 |
|---|---|---|
| `data_center_service.py::search_symbols` | `symbol_cache`(code,name) + `LIKE %q%`；未命中才拉 A股并**逐行 INSERT**；每次搜索实时调 `ak.stock_hk_spot()`（新浪**全量港股**） | 重写为只读 `symbol_dict`，删除搜索内实时 akshare 调用 |
| `data_callbacks.py::search_symbols`(回调) | `len<2` 拦截、无 debounce、`f"搜索异常: {e}"` 直接暴露技术报错 | 加 debounce、三态、友好文案 |
| `scheduler/engine.py` | `add_job` 已支持 `day_of_week`（透传 CronTrigger）；但 `add_daily_task` **未透传** `day_of_week` | 扩展 `add_daily_task` 或直接用 `add_job` 建交易日 cron |
| `data_cache_callbacks.py` | 缓存表 5 列无「名称」；`get_cached_table` 过滤仅 `ticker LIKE` | 新增名称列（join `symbol_dict`）、过滤支持名称 |
| 依赖 | 无 `pypinyin` | `pyproject.toml` 新增 `pypinyin` |

### P2 · 搜索层：匹配 / 排序 / 转义 / debounce

**R-20 输入归一化** — FR-1.2
- 文件：`data_center_service.py`（新增 `_normalize_query`）
- 要点：去首尾空格、字母转小写、全角转半角；剥离市场后缀（`.SH/.SZ/.HK`，边界 2）。
- 估时：R 0.5

**R-21 三路匹配 + 港股零填充变体** — FR-1.1 / 1.3 / 边界 1、3
- 要点：
  - 代码前缀/子串、名称子串、`pinyin_abbr` 前缀三路并集（只读 `symbol_dict`，FR-2.6）；
  - 触发阈值：≥1 字符 debounce 300ms；纯数字/纯字母仍要求 ≥2 位；
  - 纯数字输入生成零填充变体（`700`→`00700`）参与港股匹配。
- 依赖：R-10、R-20
- 估时：R 1.0

**R-22 SQL 转义（ESCAPE）** — FR-1.5 修订 / T5 / 边界 4
- 要点：对 `%`、`_` 用 `ESCAPE` 子句转义 + 参数化；`'`/`--` 作字面量；杜绝「输入 `%` 变全匹配」与注入。
- 依赖：R-21
- 估时：R 0.5

**R-23 结果排序 + 截断** — FR-1.4 / 边界 7
- 要点：优先级 代码完全 > 代码前缀 > 名称前缀 > 拼音首字母前缀 > 其余子串；同级 A股前、港股通后；最多 20 条，超出提示「结果过多，请输入更精确的关键词」。返回结构带 `match_type`（供高亮/标签/埋点）。
- 依赖：R-21
- 估时：R 1.0

**R-24 debounce 触发** — FR-1.3
- 文件：`data_callbacks.py`（回调层，Dash `debounce`/`dcc` 或客户端回调）
- 要点：停止输入 300ms 触发一次；配合 FR-3.3 加载态。
- 依赖：R-21
- 估时：R 0.5
